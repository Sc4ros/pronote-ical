Configuration

Tout se fait depuis ton téléphone. Compte environ 5 minutes.

1 Ta copie du projet

  1. Connecte-toi à GitHub, ou crée un compte gratuit ↗.
  2. Touche le bouton ci-dessous, mets pronote-ical comme nom, choisis Private, puis Create repository.
  3. Reviens ici.
Créer ma copie sur GitHub ↗
Déjà fait ?Passe directement à l'étape 2.

2 Clé d'accès GitHub

Cette clé permet à cette page de tout régler à ta place, puis aux synchros de mettre à jour tes calendriers.

  1. Touche le bouton : le formulaire est déjà pré-rempli.
  2. Dans Repository access, choisis Only select repositories puis ta copie pronote-ical.
  3. Vérifie les droits : Actions, Secrets et Gists en Read and write.
  4. Generate token, puis copie la clé github_pat_… et colle-la ici.
Créer la clé sur GitHub ↗

3 Connexion à Pronote

  1. Ouvre Pronote dans Safari (pas dans l'appli) et connecte-toi comme d'habitude.
  2. Touche l'icône QR code / téléphone en haut de la page et choisis un code à 4 chiffres.
  3. Fais une capture d'écran du QR code qui s'affiche, puis reviens ici.
⏱ Le QR code expire au bout de quelques minutes : une fois la capture faite, enchaîne directement.

    4 Ajouter les calendriers

    Touche S'abonner puis S'abonner à nouveau dans la fenêtre de l'iPhone. Ajoute ⭐ tout l'emploi du temps, ou une matière par calendrier (pour avoir les couleurs) : pas les deux, sinon les cours apparaissent en double.

    C'est fini 🎉 L'emploi du temps se met à jour tout seul toutes les 30 minutes. Tu peux fermer cette page. Pour reconnecter Pronote plus tard, reviens simplement ici.
    Rien n'est envoyé ailleurs que sur GitHub : cette page tourne entièrement dans ton navigateur.
