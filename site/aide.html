Aide et dépannage

Les problèmes les plus courants, et comment les régler depuis ton téléphone.

Mon calendrier ne se met plus à jour

Pronote a probablement déconnecté l'appareil (changement de mot de passe, rentrée, Pronote réinitialisé…).

  1. Ouvre la page de configuration et refais simplement les étapes 2 et 3.
  2. Le même calendrier secret est réutilisé : tes abonnements sur l'iPhone continuent de marcher, rien à refaire.

Pour voir l'erreur exacte : ta copie sur GitHub › onglet Actions › la dernière synchro en rouge.

« La synchro a échoué » pendant la configuration

Le plus souvent, le QR code a expiré : il n'est valable que quelques minutes. Le code à 4 chiffres doit aussi être celui choisi au moment d'afficher ce QR code. Génère un nouveau QR code, fais la capture et lance tout de suite.

« Aucun QR code trouvé » sur ma capture

Recadre la capture d'écran pour que le QR code prenne le plus de place possible, ou zoome dans Pronote avant la capture. Tu peux aussi prendre en photo un QR code affiché sur un autre écran.

« La clé n'a pas le droit… »

Sur GitHub : photo de profil › Settings › Developer settings › Fine-grained tokens › ta clé pronote-ical › Edit. Vérifie :

  • Repository access : Only select repositories › ta copie pronote-ical
  • Repository permissions : Actions et Secrets en Read and write
  • Account permissions : Gists en Read and write
Les cours apparaissent en double

Tu t'es abonné à « tout l'emploi du temps » et aux matières. Garde l'un ou l'autre : iPhone › Calendrier › Calendriers › (i) à côté du calendrier en trop › Supprimer.

Cacher les cours annulés, changer le nombre de semaines

Ta copie sur GitHub › Settings › Secrets and variables › Actions › onglet Variables › New repository variable :

  • AFFICHER_ANNULES = non pour faire disparaître les cours annulés
  • SEMAINES_APRES : nombre de semaines à venir (8 par défaut)
  • SEMAINES_AVANT : nombre de semaines passées (1 par défaut)
