📅 Pronote → iPhone

Configuration en 3 étapes. Tout se passe sur ton PC : cette page n'est pas en ligne.

1 Connexion à Pronote

  1. Ouvre Pronote dans un autre onglet, en passant par ton ENT comme d'habitude.
  2. Clique sur l'icône QR code / téléphone en haut de la page et choisis un code à 4 chiffres.
  3. Fais une capture d'écran (Windows + Maj + S) et colle-la ici avec Ctrl + V.

3 Brancher GitHub et l'iPhone

Ensuite : onglet Actions › Synchro Pronote → iPhone › Run workflow. Au bout d'environ 1 minute, il doit y avoir une coche verte ✅.

      Tout est aussi enregistré dans mes-secrets.txt. Garde ce fichier en lieu sûr et ne le partage pas.


    
B. Les calendriers à ajouter sur l'iPhone

    
Scanne un QR code avec l'appareil photo de l'iPhone, touche la bannière, puis S'abonner.
      Pour avoir une couleur par matière, scanne chaque matière. Si tu veux juste aller vite, scanne seulement « Tout l'emploi du temps ».

    

    
Le QR code ne marche pas ? Copie le lien, puis sur l'iPhone : Réglages › Calendrier › Comptes › Ajouter un compte › Autre › Ajouter un calendrier avec abonnement.


    
C'est fini 🎉 Tu peux fermer cette page et la fenêtre noire.
